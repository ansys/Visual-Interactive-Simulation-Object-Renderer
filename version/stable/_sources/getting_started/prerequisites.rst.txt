Prerequisites
#############

.. role:: ansys-gold

Check that you have the knowledge, software, and design prerequisites that
you need for running VISOR.

Python interpreter
******************

.. note::
   :class: note

   These Python versions are supported: :bdg-success:`3.11` :bdg-success:`3.12` :bdg-success:`3.13` :bdg-success:`3.14`


To use VISOR, you must have a supported Python package installed on
your system. You can download the latest version of Python from the official
`Python website <https://www.python.org/downloads/>`_, or follow the
`Python installation instructions <https://dev-docs.solutions.ansys.com/version/stable/getting_started/prerequisites/python_interpreter.html>`_
in the Ansys Solution Application Framework documentation.
