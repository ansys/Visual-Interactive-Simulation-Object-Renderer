
Use VISOR as a 3D visualization tool for solution apps. VISOR uses VTK as its internal format.
You can work with in-memory data and files in these formats:

- ``vtkPolyData``
- ``vtkUnstructuredGrid``
- ``vtkMultiBlockDataSet``
- ``vtkPartitionedDataSet``

If your source data uses another format, use a conversion tool to convert it to a VTK format.
