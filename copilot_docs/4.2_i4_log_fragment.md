## Preflight findings (read this session)

- trame-rca pushes a frame only when the server renders: at server ready, and on `trame.rca.size` /
  `trame.rca.event` (`RcaViewAdapter.update_size` / `on_interaction` → `schedule_render`). A subscriber that arrives
  after the last render sees nothing until it sends one of these (ruling 15).
- `update_size` clamps each side to at least 10 px and resizes the server window (`VisorRcaWindow` →
  `ServerRenderer.set_viewport_size(w·p, h·p)` at the next frame): from S3.1 the server window follows the client's
  element size. A size read in the constructor is 0×0 and gives a 10×10 window (ruling 15's second rejection).
- The stream subscriber receives `[payload.result]`; each message carries `name` (area) and `content` (a
  `Uint8Array` view into the whole decoded message buffer).
- `ServerApp.set_dark_theme` (`server_app.py:107–111`) → `VisorServerScene.set_dark_mode` → writes
  `_ui_state.dark_theme` (`base.py:224–227` setter), re-colours the background, requests a frame. Save reads the
  server's records (`get_state` → `_current_runtime_state` → `ui.to_persisted()`), so a server-mode save records the
  page's theme while a client-mode save records the server's own (ruling 25).
- `Trame.disconnect()` is `client.disconnect(0)` guarded by `isConnected()` (`trame.js:173–176`); the probe can call
  it again in its cleanup without a separate flag.
- wslink's `WebsocketSession.subscribe` declares its callback as `(args: any[]) => Promise<any>`; `RcaSession`
  follows it so the session needs no cast.
- `@kitware/trame/src/trame.js` is ESM and not transformed under jest (default `transformIgnorePatterns`); tests
  mock it with a factory. jsdom lacks `ResizeObserver`, `URL.createObjectURL` and JPEG decode; `devicePixelRatio` is 1.
- `LocalApp` (`local_app.py:19`) has no `set_dark_theme` trigger; only `ServerApp` does (ruling 16's rejection).
