## Silent if wrong

- **Theme change.** A theme change that does not re-colour, or a stale `_background_rgb`, still streams a valid
  picture, so no error surfaces. Pinned by the two pins and the renderer store test.
- **CSS drift.** `BACKGROUND_RGB` copies client CSS values. A later change to `public/css/theme-*.css` does not
  reach the server and nothing fails.
