## Rulings as landed

The user approved rulings 41–51 and 53–55 as proposed. Ruling 52 was approved with a clarification: cleanup disposes
only what its own effect run created. The full text is in the plan's Rulings section.

  passes `trame.state` through `stateOf(trame)`.
- 42. Every cached camera-field write fires camera-changed once all seven fields are known. This covers the seven
  setters, `setOrthographicModeAsync`, `applyOrthographicModeAsync` and a key record.
- 43. Cross-section reads before the first write reject with `CrossSectionStateUnavailableError`. No test.
- 44. Strict record shape (3/3/3/2 number arrays, a boolean, two numbers). A malformed value is logged as
  `[VISOR] server_camera_state malformed` and ignored. No test.
- 45. Six `ServerRendererCache` tests (names below).
- 46. One `UseServerVtkBuild` test pins the sender wire shape `trigger(name, [payload])`.
- 47. `UseServerVtkTheme` answers the fetch with `{schemaVersion: 3}`, asserts the order subscribe →
  `set_dark_theme` → `get_visor_scene_details_json`, and asserts that the fetch has no argument array. Names unchanged.
- 48. `AppModeBranch`'s fake `trigger` never settles. §7's stated reason was wrong.
- 49. Manual check 2 reads `(await __visorState.getCameraStateAsync()).position`.
- 50. The record pin starts with record A `[0, 0, 9]` in the key, then pushes B `[1, 2, 3]`.
- 51. Module-private `CameraRecordCache` (`static parse`, `setRecord`, `set`, `field`, `record`), plus a private static
  snapshot on `ServerRenderer`.
- 52. The effect holds a `cancelled` flag and its own local `canvas` and `renderer`. Cleanup sets `cancelled`, disposes
  that run's renderer (if built) and canvas, and resets both states to null. A build that finishes after cleanup is
  dropped, and so is a schema mismatch that arrives after cleanup. Found in the closing re-read: a renderer created
  after cleanup ran was not disposed, which leaked its `server_camera_state` watch. It is now disposed on the cancelled
  path by a shared `disposeRenderer`, which nulls the local so it is never disposed twice. That is still this run's own
  renderer, so ruling 52 is unchanged. No test covers it.
- 53. `dispose` unwatches the key and clears the camera-changed and viewer-clicked maps. Frame listeners go straight to
  `canvas.addFrameListener`.
- 54. `pickGeometryAsync` and `setGeometryHighlightAsync` reject with `GeometryPickingUnavailableError`.
  `clearGeometryHighlight` is a no-op.
- 55. `rca/ServerCanvas.ts` is not edited.
